# Version archive

Playable copies of every major version of Verity Sanctuary, for reference.

- Open `versions/index.html` to pick a version, or open `versions/v1.0/index.html` directly.
- Each archived copy uses its own save slot, so playing an old version never touches your main save.
- To archive a new version, run from the `tycoon` folder: `versions/archive.sh 1.2 "Title"`
